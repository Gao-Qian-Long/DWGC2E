## 布局结构变化

### 关于
- 从连续文本堆叠改成版本、服务状态、帮助三个独立区域。
- 版本组包含品牌名称、英文副标题、版本信息和检查更新操作；保留已有更新命令，不新增服务。
- 服务状态采用两条 52 DIP 状态行，检测按钮放在状态组操作区，绑定真实已有文本，不新增服务健康判断。
- 删除关于正文中的设置保存反馈；关于页仍不显示保存栏。
- 关于正文最大宽 820 DIP，其余设置保持 740 DIP；二级导航与正文间隔 32 DIP。

### 图纸翻译
- 外层 Grid 分成标题、账户条、可滚动正文、固定底部操作栏。
- 正文按拖入/队列、翻译设置、输出、运行日志四行布局；不再让配置、输出和 Footer 共用一行。
- 拖入区用 Grid 的水平与垂直居中排布图标、标题、说明、选择按钮，不使用横向偏移模拟居中。
- 语言行采用 220 / 48 / 220 / * 列，源与目标等宽，交换按钮有提示。术语库另起一行。
- 输出路径省略截断并保留完整 Tooltip，打开目录与输出设置同属输出区域。
- 翻译、取消任务、导出、取消导出保留原命令；未翻译时导出按钮禁用，主操作固定在 Footer。
- 小窗口正文滚动，队列表格有独立有界高度；日志展开后可滚动到完整日志，不再将拖入区内容压碎。

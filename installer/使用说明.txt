DWGC2E — CAD 图纸翻译工具

一、安装与开始使用
1. 下载文件名包含 GstarCAD 的 Setup.exe，双击安装。无需解压文件夹、执行脚本、安装开发工具或填写模型 API Key。
2. 默认安装到 D:\DWGC2E；没有可用 D 盘时为 C:\DWGC2E。可选择其他有写入权限的目录，升级沿用原目录。开发者不要选择源码目录，安装器会拒绝覆盖源码。
3. 从桌面或开始菜单启动，登录账户，导入图纸、选择语言、翻译、审阅，再导出。使用云端翻译需要网络及有效账户/额度。
4. 导出 DWG 需要本机已有与本包匹配的浩辰 CAD。当前交付平台是 GstarCAD，不是 AutoCAD 通用安装包。请先用副本验证自己的 CAD 版本和图纸，再批量处理。

二、程序已经包含什么
Windows x64 自包含应用、CAD 插件、默认设置和默认术语库均在安装器中，安装时自动释放。AI 提示词与模型凭据仅保存在服务端，客户端不会安装 prompts；用户也不需要单独下载 DLL、.NET 8 运行时或复制 glossaries 文件夹。
程序不是 CAD 安装器，不会替您安装或授权 CAD。CAD 宿主及其运行环境仍需正常可用。
通常不需手工安装插件；导出时程序会尝试自动加载。遇到 CAD 检测或加载问题，打开“环境自检与安装”查看具体原因，按需安装/修复插件。宿主安全策略可能要求用户确认；安装器不能保证所有 CAD 版本零操作兼容。

三、数据与升级
个人设置、术语库、日志等通常位于 %APPDATA%\DwgTranslator。已设置自定义数据目录的用户继续使用原目录。
升级前保存工作并关闭 APP/CAD 中相关作业，然后运行新版 Setup。安装器保留个人设置和术语库；不要把安装目录当作图纸备份目录。
卸载通过 Windows“已安装的应用”执行。个人数据不会作为程序文件自动清除；需要删除账户数据时先备份，再单独处理。

四、常见问题
无法翻译：检查网络、登录状态、账户额度以及程序提示；不需要配置服务商密钥。
无法导出 DWG：确认已安装匹配平台 CAD，查看环境自检与日志。请勿把 AutoCAD 插件 DLL 与 GstarCAD 包混用。
安装路径冲突：更换目录，不要删除源码标记或强行覆盖。
Windows 安全提醒：仅运行可信来源下载的安装器，可与 SHA256SUMS.txt 核对。本包如未签名，可能出现安全提示；不要关闭系统安全防护。
反馈时提供版本、CAD 版本、错误说明及必要日志。日志或图纸可能含个人信息，请先脱敏。

发行文件：Setup.exe 是必须文件；开始使用.txt 与 SHA256SUMS.txt 是说明和校验文件。源码、release 文件夹、测试报告和个人配置不应作为用户下载内容。

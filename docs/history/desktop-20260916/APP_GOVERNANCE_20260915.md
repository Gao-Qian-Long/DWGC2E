# APP 2.1.1 治理候选版（2026-09-15）

## 本批已实施

- 安装编号持久化失败时明确失败，不再回退临时随机编号。
- WorkerApiClient 提取请求传输、会话版本检查；兼容旧登录接口，新增服务端退出。
- 本机任务、翻译缓存、术语与默认导出目录按服务端 user_id 的 SHA256 分目录。
- TaskManager 空闲时切换存储，先保存旧任务，不把两个账号的队列合并。缓存切换落盘并清空内存。
- 登录、退出和导入/导出互斥；旧会话的迟到界面事件不会更新新会话。
- 未保存术语在换号前走已有离开确认；默认随包词库与历史可编辑目录分离。
- 旧无归属任务/缓存/术语不自动认领到新账号；安装编号、通用外观配置仍为安装级别。

目录：`AppDataDir/accounts/<SHA256(user_id)>/{tasks.json,translation_cache.json,glossaries/,exports/}`；未登录为 guest。账号路径不使用用户名直接拼接，不能通过路径字符串跳出根目录。

## 自动验证与限制

核心测试 93/93；受控 WPF UI smoke 通过。新增设备存储、会话、账号目录/缓存/任务隔离测试。APP 构建和插件打包校验通过，版本号 2.1.1。

当前机器解析到 **GstarCAD** 插件构建环境。构建成功不是 AutoCAD 实机测试，也不是已证明全部 CAD 版本兼容。因此本候选包不替换官网的公开安装包，不把它冒充正式 AutoCAD 通用版。

两个 GitHub 源仓库都是私有仓库；现有蓝奏云下载目标未获得可验证的新包上传通道。本批不修改仓库公开性、不建立公开源码镜像、不把私有 Release 链接当成匿名下载入口。

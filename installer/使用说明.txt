DWG Translator —— CAD 图纸翻译工具
============================================

【这是什么】
把机械/电气 CAD 图纸里的中文（或英文）批量翻译成另一种语言，并写回 DWG 图纸本身：
文字位置、字号、字体、句柄都按原图自动适配，不需要人工逐条改。支持一次导入多张图纸、
批量导出，翻译结果可导出为 Excel 人工校对后再导回。

支持的语言：简体中文、繁体中文、English、日本語、한국어、Русский、Deutsch、Français、
Español、Português、Italiano、Nederlands、Polski、Türkçe、Tiếng Việt、ไทย、Bahasa
Indonesia、العربية。任意两种语言之间都可以互译，在标题栏中间的语言按钮里选择。


【系统要求】
1. Windows 10 / 11（64 位）。
2. 不需要安装 .NET 运行时：程序是自包含发布，双击即用。
3. 需要本机已安装 CAD 才能把译文写回图纸：
   - 与安装包平台标记匹配的浩辰CAD 2024，或 AutoCAD 2025 及以上版本。
   - GstarCAD 与 AutoCAD 插件 DLL 不通用；程序会检查 CadPlugin\cad-platform.txt 并拒绝错误宿主。
   - 未安装 CAD 时程序仍可用来查看、翻译、导出 Excel。


【安装步骤】
方式一（推荐，双击即可）：
  1. 解压整个压缩包到任意目录（不要只解压 exe，程序需要同目录的 CadPlugin 等文件）。
  2. 双击 “安装.cmd”，按提示完成。
     - 程序安装到：%LOCALAPPDATA%\Programs\DwgTranslator
     - 自动创建开始菜单快捷方式（桌面快捷方式可选）
     - 不需要管理员权限
  3. 安装完成后程序会自动打开。

方式二（绿色免安装）：
  直接双击解压目录里的 DwgTranslator.exe 使用，不写注册表、不装服务。
  唯一区别是开始菜单里没有快捷方式。


【首次配置】
1. 打开程序 → 右上角「更多 ▾」→「环境自检与安装…」：
   - 可以看到程序版本、运行环境、检测到的 CAD、CAD 插件状态、接口配置状态。
   - 点「安装 / 修复插件」把 CAD 插件装进本机的 CAD。
     （不装也能用：每次导出时程序会自行加载插件，这一项只是让 CAD 里也能直接调用命令。）
2. 点标题栏右侧的齿轮「设置」，填入翻译接口的 API Key，保存。
   接口地址默认 https://api.deepseek.com，默认模型 deepseek-v4-flash。


【使用流程】
1. 导入图纸：把一张或多张 .dwg / .dxf 直接拖进窗口，或点「导入 DWG」多选。
2. 选语言：点标题栏中间的语言按钮，选择「原文语言 → 目标语言」。
   （切换语言会清空当前图上已有的译文，需要用新语言重新翻译；已翻译过的句子在本地缓存里，
   不会重复消耗接口额度。）
3. 点「翻译」。程序会去重后并发翻译，进度在窗口顶部显示。
4. 检查：在列表里逐条核对，可点「全部审阅」批量确认；也可以点「导出 Excel」导出校对表，
   用 Excel 改完后「导入 Excel」回填。
5. 点「导出 DWG」：
   - 单张图纸：选择输出文件名，写入 *_translated.dwg。
   - 多张图纸：只需选择一个输出文件夹，程序会把每张图各自导出成「原名_translated.dwg」。
6. 在 CAD 中打开导出的 dwg 检查效果。若个别文字未翻译，看窗口底部状态栏与「日志」面板，
   或把 %APPDATA%\DwgTranslator\logs 下的日志一起反馈。


【CAD 插件怎么用】
程序内部已经包含插件（CadPlugin\DwgTranslator.Cad.dll），导出时自动加载。
如果希望在自己的 CAD 里直接调用，用「环境自检与安装」安装后，在 CAD 命令行输入：

    DwgTranslateWrite

即可对当前图纸执行写回（需要由本程序先生成写回配置）。

插件安装/卸载都是可逆的：只会在 CAD 的 Support 目录下新增 DwgTranslator 文件夹，并在
acaddoc.lsp 中写入一段带标记的自动加载配置；安装前会备份原有 acaddoc.lsp，卸载时只删除
程序自己写入的内容。


【常见问题】
Q: 提示 “Translation failed” / 翻译一直失败？
A: 多半是 API Key 无效或余额不足。打开「设置」→ 测试连接确认；状态栏和日志会给出具体原因。

Q: 导出的图纸里个别文字没翻译（还是中文）？
A: 那是回写时的布局保护：译文太长、周围图元会让它压到别的文字时，程序会退回原文而不是画出
   一张脏图。可在日志里搜 “Original text preserved after layout rejection” 看到具体是哪些
   文字，或把该处译文改短（导出 Excel 校对表改完后导入）再导出。

Q: 程序打不开 / 报缺少运行时？
A: 确认下载的是完整压缩包（含 exe 与 CadPlugin 文件夹），且已全部解压。

Q: 换电脑之后要重新配置吗？
A: 要。API Key 保存在 %APPDATA%\DwgTranslator\settings.json，程序不联网同步配置。

Q: 翻译缓存和数据放在哪？
A: %APPDATA%\DwgTranslator —— 含 settings.json（配置）、translation_cache.json（翻译缓存）、
   logs（日志）、exports（导出目录）。卸载程序不会删除这些数据，可自行备份或清理。


【卸载】
开始菜单 → DWG Translator → 卸载；或运行安装目录下的 卸载.cmd。
卸载只删除程序文件与快捷方式，用户配置和翻译缓存会保留。
